# 録音した 声 を いれる ところ

録音した音声ファイルは、この `audio/` フォルダに置いてください。

- ファイル形式：**.mp3**
- ファイル名：`docs/voice-script.csv` の **ID とまったく同じ名前**にする
  - 例：`kana-001.mp3`、`pet-001-animal.mp3`、`story-003.mp3`
- サブフォルダは作らず、全部このフォルダに直接置く

## 入れたあと（2026-11-15〜）

声を入れたら、Claude に「声を反映して」と言うか、次を実行します。

```
node tools/build_voice_ids.js
```

- `docs/voice-script.csv` の ID と、このフォルダのファイルを照らし合わせて、`kids-app/voice-ids.js`（声の表）を作りなおします
- アプリは、しゃべる言葉がこの表にあれば録音を流し、なければこれまでどおり機械の読み上げにします
- **どの ID でも**（あいぼう・せんかき・おはなし・ことば など）、ファイルを入れて表を作りなおすだけでつながります
- キャラごとの声（`-animal`／`-car`／`-veggie`）は、いまのあいぼうの声だけを使います（ほかのキャラの声では代わりに読みません）
- 名前（よびかけ）が入る言葉は、録音とは文が変わるので読み上げのままです
