# 録音した 声 を いれる ところ

録音した音声ファイルは、この `audio/` フォルダに置いてください。

- ファイル形式：**.mp3**
- ファイル名：`docs/voice-script.csv` の **ID とまったく同じ名前**にする
  - 例：`kana-001.mp3`、`pet-001-animal.mp3`、`story-003.mp3`
- サブフォルダは作らず、全部このフォルダに直接置く

## いまの対応状況（2026-11-13）

「1もじ の よみ」（ひらがな・濁音・半濁音、`kana-001`〜`kana-071`）だけ、
この仕組みに対応しています。このIDのファイルをここに置くと、
次に開いたときから自動でその録音が再生されます（ファイルがなければ
これまでと同じ機械の読み上げになります）。

それ以外のID（`word-`、`story-`、`count-` など）は、まだこの仕組みに
つながっていません。録音が増えてきたら、ツール開発の部署につないで
もらってください。
