# きょうの おけいこ の しくみ（2026-11-12）

> 代表の依頼：年齢ごとに中身を決めたい。設定が見える・こちらでも調整できるように。初期設定があっても、親が選べるとなおよい
> 年齢ごとの中身は **おすすめ（たたき台）** です。決めるのは代表です。

## しくみ（ひとことで）
1. **年齢のめやす** を選ぶ（保護者メニュー → 今日のおけいこ）。選んでいないときは「4歳1か月〜4歳6か月」（いままでの おけいこ と同じ）
2. その年齢の **おすすめの中身** が、毎日の「きょうの おけいこ」になる
3. 親が「中身を見る・変える」で、**その子だけの中身** に変えられる（＋／−で問題の数。0で外す。足した順に進む。「おすすめに戻す」で元どおり）
4. 毎日 0時に その日の おけいこ が つくられる。設定を変えると、その日の分も すぐ つくりなおす（もう やった分は のこる）
5. どの年齢でも、**にがて** があれば字の練習のあとに1〜2こ入る。字を ひととおり終えた子は自動で次へ（せんかき は半分／ひらがな → カタカナ／よもう → ものがたり）
6. 全部できたら おやつ1こ（いままでと同じ）

- 推測：2歳の1回の集中は数分なので、2歳は合計を少なくした。お子さんで試して、多すぎ・少なすぎを見て直すのがよい
