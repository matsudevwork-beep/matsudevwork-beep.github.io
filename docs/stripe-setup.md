# Stripe の 登録 と 準備（2026-11-26）

ぶにゅう の 有料プラン の お金 を 受け取る サービス です。カード情報 は Stripe だけ が 持ち、アプリ と サーバー には 届きません。

- **登録・ログイン・お金 に かかわる 設定 は ぜんぶ 代表** が 行います（Claude は ログイン しない）
- **秘密 の カギ（`rk_…`・`sk_…`）は チャット に 貼らない・ファイル に 書かない**
- まず **テスト（お金 が 動かない 練習 の 場所）** で 全部 作って、開発用サーバー で ためします。本番 の 申請 は そのあと
- 画面 の 名前 は Stripe が ときどき 変える ので、少し ちがって いたら 近い 名前 を さがして ください

---

## 1. アカウント を 作る（15分）
1. https://stripe.com/jp を 開いて「今すぐ始める」
2. メールアドレス：**開発用（matsu.dev.work@gmail.com）**、氏名、国＝日本、パスワード
3. 届いた メール の リンク を 押して 確認
4. **2段階認証 を 設定**（スマホ の 認証アプリ か SMS）。お金 の アカウント なので 必ず
5. 「事業 の 情報 を 入力」は **まだ しなくて よい**（本番 の 申請 の とき に 7. で やる）

## 2. テスト の 場所 に 切りかえる（1分）
- 画面 の 上 の「テスト環境」「サンドボックス」などの 切りかえ を オン（画面 の ふち に「テスト」と 出る）
- 3.〜6. は **ぜんぶ テスト の 場所 で** 行います

## 3. 商品 と 値段 を 作る（10分）
「商品カタログ」→「商品を追加」
- 名前：`ぶにゅう 有料プラン`
- 説明：`幼児向け学習アプリ。すべての遊び・あいぼう3体・きょうだい3人まで・端末5台まで`
- 値段 1：**780円・継続・毎月**
- 値段 2：「別の価格を追加」→ **7,800円・継続・毎年**
- 税 は「価格に税を含む」（780円 が 税込）を えらぶ。えらぶ 所 が なければ そのまま で よい
- 先着50家庭 の 580円／5,800円 は、あとで 同じ 商品 に 値段 を 足します（いまは 作らなくて よい）

## 4. 支払いリンク を 作る（10分）
「支払いリンク」→「新規作成」→ 3. の 商品 の **月額 780円** を えらぶ
- 「支払い後」の ところ：**「ウェブサイトにリダイレクト」**（自分 の ページ へ もどす）を えらび、次 を 入れる
  `https://bunyu-dev.matsu-dev-work.workers.dev/?bought=1`
  （払った あと アプリ に もどり、「購入済みの方の確認」が 自動 で 開きます）
- 「数量の調整」「プロモーションコード」は オフ
- 「作成」→ 出てきた リンク（`https://buy.stripe.com/test_…`）を コピー
- 同じ ように **年額 7,800円** の リンク も 作る
- → **2つ の リンク を チャット で 教えて ください**（これ は 秘密 では ない）。Claude が アプリ（`paywall.js` の `PAY_LINKS_TEST`）に 入れます（**2026-11-26 済み**。本番 の リンク は 8. の あと `PAY_LINKS_LIVE` に）

## 5. 解約 できる 画面 を 用意 する（5分）
「設定」→「Billing」→「カスタマーポータル」
- 「解約 を 許可」を オン（すぐ 解約 では なく「期間 の 終わり に 解約」を えらぶ）
- 「支払い方法 の 更新」を オン
- 保存 → 出てくる ログイン用 の リンク を コピー して 教えて ください（アプリ の プラン の 画面 に「解約・カードの変更」として 出します。**2026-11-26 済み**：`paywall.js` の `PORTAL_LINK`。有料 の 端末 と「購入済みの方の確認」に 出る）
- 解約 が かんたん に できる こと は「安心 して 使える」の アピール に なります

## 6. サーバー 用 の カギ を 作って 入れる（10分）
「開発者」→「APIキー」→「制限付きのキーを作成」
- 名前：`bunyu-dev 読むだけ`
- 権限：**Customers＝読み取り、Subscriptions＝読み取り**。ほか は ぜんぶ「なし」
- 作成 → `rk_test_` で 始まる カギ が 出る（**1回 しか 見えない**。頭 が `rk_test_` か 確かめる）
- Mac の ターミナル で：
  ```bash
  cd ~/Documents/WORK/omakase-ai-company/08_kids-app/app/worker
  ```
  ```bash
  npx wrangler secret put STRIPE_SECRET --env dev
  ```
  「Enter a secret value」と 出たら カギ を 貼りつけて Enter（画面 に は 出ません）
- 終わったら「入れた」と 教えて ください（カギ そのもの は 教えない）

## 6-2. Resend（確認コード の メール を 送る）を 入れる（15分・2026-11-26 代表：まず テスト用 の 差出人 で）
1. https://resend.com で「Get Started」→ **開発用 の メールアドレス** で 登録（Google で 登録 でも よい）。届いた メール で 確認
2. 「Add domain」（ドメイン の 登録）は **しない**（ドメイン を 決める まで）
3. 左 の「API Keys」→「Create API Key」→ 名前 `bunyu-dev`、権限 **Sending access（送るだけ）**、Domain は「All domains」→ 作成
4. `re_` で 始まる カギ が 出る（1回 しか 見えない）。ターミナル で：
   ```bash
   cd ~/Documents/WORK/omakase-ai-company/08_kids-app/app/worker
   ```
   ```bash
   npx wrangler secret put RESEND_KEY --env dev
   ```
   貼りつけて Enter。チャット には 貼らない
- 差出人 は Resend の テスト用（`onboarding@resend.dev`。`wrangler.toml` の 開発用 の `MAIL_FROM`）。**Resend に 登録 した メールアドレス あて に だけ 送れる** → 7. の テスト で 買う とき は その メールアドレス を つかう
- 本番 の 前 に ドメイン を 決めて「Add domain」→ Cloudflare に しるし（DNS）を 入れる → `MAIL_FROM` を `no-reply@ドメイン` に

## 7. テスト で 買って みる（Resend の 準備 の あと・15分）
確認コード の メール を 送る Resend（`RESEND_KEY`）を 入れた あと に 行います。
1. 開発用 の 住所 → 料金 の 画面 →「月額で始める」→ Stripe の 画面
2. テスト用 の カード：`4242 4242 4242 4242`・期限 は 未来 の 月／年・セキュリティコード は 3けた なら なんでも（お金 は 動きません）
3. アプリ に もどる →「購入済みの方の確認」→ メール に 届いた 6けた の コード → 有料 に なれば 成功
- **2026-11-26 代表 が テスト で 成功**：有料 に なった／料金 の 画面 の「解約・カードの変更」から Stripe に 入れた／解約 は「期間 の 終わり」（12月26日）に なった
- まだ 見て いない こと：解約 の 日 が すぎた あと、アプリ が 3日 に 1かい の 聞きなおし で 無料 に もどるか（12月26日 の あと に たしかめる）

## 8. 本番 の 申請（無料版 を 公開 する 前・30分＋審査 待ち）
テスト が 全部 うまく いってから。「アカウントを有効化」で 次 を 入れます。
- 事業 の 形（個人事業主）、名前、住所、電話番号、業種（ソフトウェア・アプリ）
- サービス の 住所（本番 の URL）と 商品 の 説明
- 売上 が 入る 銀行口座、本人確認書類（運転免許証 など）
- 明細書 に 出る 名前（カード の 明細 に 出る）：例 `BUNYU`【代表 が 決める】
- **特定商取引法に基づく表記 の ページ** が サイト に いる（日本 で 売る とき の きまり。審査 で 見られる）。住所・電話番号 は「請求 が あれば すぐ 開示します」と 書く 方法 も ある【代表 が 決める。ページ は Claude が 下書き】
- 本番 の カギ（`rk_live_…`）は 本番 の サーバー に だけ 入れる（`--env dev` を つけない）

- カード 決済 の 手数料 と、サブスク（Billing）の 手数料 が かかります。780円 から 引かれる 金額 は 本番 の 前 に 公式 で 確かめて、`../plan/` の 売上計画 に 入れます
