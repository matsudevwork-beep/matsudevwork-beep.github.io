# 声 を ならす しくみ（引きつぎ用・2026-11-16）

> 声（録音・よみあげ）に さわる まえ に、かならず この ファイル を 読む。
> ちがう 会話（セッション）で 直しても、ここ の「やっては いけない こと」を まもれば こわれない。

## ぜったい に やらない こと（iPhone で こまる）
| やらない こと | なぜ | いつ わかった |
|---|---|---|
| `<audio>` タグ・`new Audio()` で ならす | iPhone の カメラ の よこ（ダイナミックアイランド）に「再生中」の しるし が 出る | 2026-11-14 |
| `navigator.audioSession.type = "playback"` | おなじ しるし が 出る（11-15 に マナースイッチ 対策 で 入れて、11-16 に 代表 の 指摘 で 外した） | 2026-11-16 |

- 音 は **Web Audio（`AudioContext` ＋ `AudioBufferSourceNode`）だけ** で ならす。
- そのため、iPhone の マナー（おと なし）スイッチ が オン の とき は、録音 の 声 は 鳴らない。これは iPhone の きまり。だまって しまう より、しるし が 出ない ほう を えらんだ（代表 2026-11-16）。
- `node tools/build_voice_ids.js` を うごかす と、上 の 2つ を つかって いたら ⚠ を 出す。

## iPhone で 音 を 出す ため に ひつよう な こと（けさない）
- `unlockAudio()`（app.js）：タップ する たび に 音 の しくみ を おこす。iPhone は「タップ の なか で うごかした 音」しか ならさない。
- 音 の しくみ が まだ とまって いる とき は、だまらず に 端末 の よみあげ に きりかえる（`audioStart` の なか）。

## 声 の えらびかた（`speak(text)`）
1. **文 まるごと の 録音** が あれば それ（`voice-ids.js` の 表）
2. なければ **部品 を つないで**（`kids-app/voice-parts.js` の `VoiceParts.plan`）
   - 例：「し」を かこう！ ●から ★へ なぞってね → `し`（1もじ）＋`を かこう！ まるから ほしへ なぞってね`（部品）
   - 例：ゆうとくん、こんにちは！ きょうも あそぼ → `ゆ`＋`う`＋`と`＋`くん`＋`こんにちは！ きょうも あそぼ`
   - すうじ は よみ に して から さがす：3 → さん、3こ → さんこ、4じ → よじ、15ふん → じゅうごふん
   - 1もじ の 録音（kana-）は **なまえ と「」の なか の 1もじ だけ** で つかう（表 では `#あ` の なまえ）
   - ふつう の 文 の なか の 1もじ 部品（「と」「は（わ）」「に」）は 1つ の 文 で 3つ まで
   - つなぐ とき は 録音 の まえ と うしろ の むおん を けずって、0.06びょう あけて ならべる（なまえ の 字 どうし は すきま なし）
3. つなげない とき は **文 ぜんぶ を よみあげ**（とちゅう で 録音 と よみあげ が まざらない）

## 録音 を ふやす とき の ながれ
1. せりふ を かえる・たす → `tools/build_voice_list.js` を なおす → `node tools/build_voice_list.js`（`docs/voice-script.md`／`.csv`）
   - 字・すうじ・なまえ・もの の なまえ が かわる 文 は **部品 に わけて** たす（字 ごと に 1文 ずつ 録音 しない）
   - もう 録音 した ID が ずれない ように、あたらしい 行 は その しゅるい の **さいご** に たす
2. `node tools/check_voice_parts.js` で、アプリ の 文 が 部品 で つながるか たしかめる（× は よみあげ に なる 文）
   - じぶん で 文 を ためす：`node tools/check_voice_parts.js "「し」を かこう！ ●から ★へ なぞってね"`
3. 録音 した mp3 を `kids-app/audio/<ID>.mp3` に いれて `node tools/build_voice_ids.js`
4. `sw.js` の `CACHE` の ばんごう を あげる

## まだ の こと・気をつける こと
- **声 の ぬし**（2026-11-16 代表 決定）：あいぼう 以外 の 声（1もじ・部品・せんかき の 声かけ・かず など、ID の うしろ に `-animal` が ない もの）は **ぜんぶ こぐまん の 声**（VOICEVOX：ずんだもん あまあま）で 録る。しょべるん・キャロ を えらんで いる とき も、なまえ や 部品 は こぐまん の 声 に なる。キャラ ごと の 声 は `-animal`／`-car`／`-veggie` の ID だけ

- なまえ に「っ」が ある とき（いっせい など）と、のばす「ー」は まだ つなげない（ー は よまず に とばす）
- レベル アップ の ことば：レベル2〜10（lvup-001〜027。10 は 2026-11-16 に たした）。シート で なおす → CSV を `docs/voice-script-edited.csv` に おく → `node tools/apply_voice_edits.js --apply` で characters.js の その キャラ の `voiceStages` が なおる（図鑑 の `stages` は かわらない）
