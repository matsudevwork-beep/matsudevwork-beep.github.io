## ぜったい に やらない こと（iPhone で こまる）

- そのため、iPhone の マナー（おと なし）スイッチ が オン の とき は、録音 の 声 は 鳴らない。これは iPhone の きまり。だまって しまう より、しるし が 出ない ほう を えらんだ（代表 2026-11-16）。
- `node tools/build_voice_ids.js` を うごかす と、上 の 2つ を つかって いたら ⚠ を 出す。

## iPhone で 音 を 出す ため に ひつよう な こと（けさない）
- `unlockAudio()`（app.js）：タップ する たび に 音 の しくみ を おこす。iPhone は「タップ の なか で うごかした 音」しか ならさない。
- 音 の しくみ が まだ とまって いる とき は、だまらず に 端末 の よみあげ に きりかえる（`audioStart` の なか）。
- **とちゅう で 声 が 出なく なる・たまった 声 が いっき に 出る の を ふせぐ**（2026-11-21 代表）
  - iPhone は 通知・電話・ほか の 音・しばらく さわらない など で 音 の しくみ を とちゅう で とめる。`unlockAudio` は **タップ の たび に** みる（まえ は 1かい うごいたら みはり を やめて いて、とまった あと 二度と おきなかった）。とまって いて、作って 1びょう いじょう たって いれば 作りなおす（`audioCtxBorn`）
  - **アプリ を とじて ひらきなおすと 音 が 出ない**（2026-11-21 代表）：iPhone は もどった とき「うごいて いる」と いいながら 音 が 出ない ことが ある → とじたら（visibilitychange・pagehide）`audioNeedsFresh` の しるし を つけ、**つぎ の タップ で かならず 作りなおす**。その とき ならし はじめて いた 声 は あたらしい ほう で ならしなおす（さわった しゅんかん に 声 を 出す あそび の ため）。ふるい ほう の 待ち（`audioStart` の なか）は `ctx !== audioCtx` で やめる
  - 端末 の よみあげ は、とまって いる あいだ に たのんだ 声 を なか に ためて、あとで まとめて ながす → たのむ まえ に かならず `speechSynthesis.cancel()`（`ttsStart`）
  - まって いる 声 は 4びょう いじょう まえ の もの を すてる（`speechFinish`。`item.at`）。アプリ が うしろ に まわったら 声 を ぜんぶ とめる
- **まえ の 声 を きる**（2026-11-22 代表：2かくめ・3かくめ を かいて いる のに まだ まえ の こと を 言って いた）：子ども が さわる（pointerdown・touchstart・keydown）たび に `actSeq` を ふやす。あたらしい 声 が きた とき、いま の 声 が その まえ の タッチ より まえ に たのまれた もの なら（2.5びょう いない に さわって いる とき）、まって いる 声 も ふくめて すぐ やめる（`speechEnqueue`）。さわって いない あいだ の じゅんばん の 声 は いままで どおり。つづけて 言う ばめん は `whenQuiet` で つなぐ（いっしょに よもう の せーの！）
- **1つ の 録音 も まえ・うしろ の むおん を けずる**（2026-11-22：せーの！ の あと の 間 が ながかった。ElevenLabs の 声 は おわり に 1びょう ほど むおん）
- **その 場面 だけ の 録音**（numcard-：すうじ の カード。2026-11-22 代表：かぞえる 声 だと イントネーション が へん）：表 では `@numcard-001` で のせ、おなじ ことば の ほか の 録音 とは まざらない。`speakOwn(id, text)` は 録音 が なければ 端末 の よみあげ（ほか の 録音 には しない）
- **おと の ボタン は もどる の となり に おかない**（2026-11-21 代表：しらない うち に オフ に なって いた）。あいぼう の みぎ。オン・オフ を かえたら 画面 に「おと を けしたよ」と 出る。オフ の あいだ は 赤い わく

## 声 の えらびかた（`speak(text)`）
1. **文 まるごと の 録音** が あれば それ（`voice-ids.js` の 表）
2. なければ **部品 を つないで**（`kids-app/voice-parts.js` の `VoiceParts.plan`）
   - 例：「し」を かこう！ ●から ★へ なぞってね → `し`（1もじ）＋`を かこう！ まるから ほしへ なぞってね`（部品）
   - 例：ゆうとくん、こんにちは！ きょうも あそぼ → `ゆ`＋`う`＋`と`＋`くん`＋`こんにちは！ きょうも あそぼ`
   - すうじ は よみ に して から さがす：3 → さん、3こ → さんこ、4じ → よじ、15ふん → じゅうごふん
   - 1もじ の 録音（kana-）は **なまえ と「」の なか の 1もじ だけ** で つかう（表 では `#あ` の なまえ）
   - ふつう の 文 の なか の 1もじ 部品（「と」「は（わ）」「に」）は 1つ の 文 で 3つ まで
   - つなぐ とき は 録音 の まえ と うしろ の むおん を けずって、0.06びょう あけて ならべる
   - **なまえ の 1もじ（kana-）** は 声 の 出はじめ・おわり の よわい ところ（いちばん 大きい ところ の 12% より 小さい）も けずり、はし を ふわっと して **すこし かさねて** つなぐ（つぎ の 字 は まえ の 字 の 55%〜「おわり の 0.08びょう まえ」で はじまる。「くん」「ちゃん」の まえ は 0.03びょう まえ）。2026-11-20 代表：1おん 1おん が あいて きこえた → 「ゆうと」が 約0.9びょう → 約0.5びょう。`trimmedOf`・`audioStart`（app.js）
   - **1もじ を 1つ だけ ならす とき**（いっしょに よもう で 字 を さわった など）は、はじめ の むおん だけ けずって すぐ 鳴らす（`leadTrimmedOf`。2026-11-21 代表：さわって から おそい。1もじ の 録音 は はじめ に 0.1〜0.3びょう の むおん が ある）。いっしょに よもう は ひらいた とき に その ことば の 字 の 声 を さき に よみこむ（`preloadAudio`）
3. つなげない とき は **文 ぜんぶ を よみあげ**（とちゅう で 録音 と よみあげ が まざらない）

## よみ が おなじ ことば は 1かい だけ 録音（2026-11-19 代表）

- スプレッドシート から 行 を けす とき は、ID を たしかめて その 行 だけ けす（ならび が ローカル と ちがう）

## 録音 を ふやす とき の ながれ
1. せりふ を かえる・たす → `tools/build_voice_list.js` を なおす → `node tools/build_voice_list.js`（`docs/voice-script.md`／`.csv`）

2. `node tools/check_voice_parts.js` で、アプリ の 文 が 部品 で つながるか たしかめる（× は よみあげ に なる 文）
