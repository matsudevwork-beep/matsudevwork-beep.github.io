# セキュリティチェック（2026-11-24・Codex）

対象：無料プラン・トライアル・有料の確認・計測（`kids-app/plan.js`・`track.js`・`paywall.js`・`sw.js`・`app.js` の変更・`worker/`）
やり方：Codex に「見るだけ」で調べてもらい、Claude がなおした

## 見つかったこと → なおしたこと
| 重さ | 内容 | なおし方 |
|---|---|---|
| 中 | 確認コードの「5回まで」を、同時にたくさん送るとこえられる（6けたを当てずっぽうで試せる） | 回数を1つ増やすのと上限の判定を **1つのSQL** でまとめた。さらにメールごとに1時間10回まで（`worker/src/index.js` の `paidFinish`） |
| 低 | 買った人のメールだけ返事が少しおそくなり、「この人は買った」と推測できるかも | Stripe への問い合わせとメール送信を **返事のあと** にした（`ctx.waitUntil`）。どのメールでも同じ速さ・同じ返事 |
| 低 | 開発用のプラン切りかえが `*.localhost` でも出る | `localhost`・`127.0.0.1`・`[::1]` の3つだけにした |

## 問題なしと確認されたこと
- 公開リポジトリに秘密のカギ（Stripe・メールサービス）は入っていない
- 子どもの名前・記録は送っていない。計測の番号と有料確認の番号は別（つながらない）
- IPアドレスは回数を数えるためだけに使い、ハッシュで保存（1時間で消える）
- 子ども向けロック画面から料金・トライアルへ行く道は、すべて保護者のカギ（かけざん）を通る
- 「コードを送る」の返事は、買った人でも買っていない人でも同じ
- サービスワーカーは `/api` の返事をためない
- データベースへの書きこみは安全な書き方（SQLインジェクションなし）
