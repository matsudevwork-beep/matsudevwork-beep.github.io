# ChatGPT で こぐまん の 表情 を 作ってもらう プロンプト

2026-11-20 作成。こぐまんの顔パーツ（`docs/parts-drawing-guide.md` の 目・笑った目・とじた目・口・あけた口）を ChatGPT の画像づくりで用意するための手順とプロンプトです。

---

## 考え方（なぜ この やり方 か）

- ChatGPT に「目だけ」「口だけ」を白紙に描いてもらうと、**大きさ・位置が合わず**、重ねたときにずれます。
- そこで、**代表の絵をそのまま渡して「顔だけ表情を変えた絵」を1枚ずつ作ってもらいます**。
- できた絵から、Claude が **目と口のところだけを切り出して** パーツにします（体の線が少しずれても、使うのは顔だけなので大丈夫）。
- 「ふつうの目」「ふつうの口」は、いまの絵から切り出せるので、ChatGPT に頼むのは **ちがう表情のぶんだけ** です。

## 手順

1. ChatGPT で **新しいチャット** をひらく（前の会話のえいきょうを受けないように）。
2. `level-02.png` と キャラクター設定資料 の2枚を添付して、下の **【さいしょのプロンプト】** をそのまま貼って送る。
3. 1枚目（にっこり）ができたら、下の **チェックリスト** で見る。ダメなら **【やり直しのプロンプト】** を送る。
4. OKなら **【2枚目以降のプロンプト】** を順番に送る（1回に1枚）。
5. 4枚できたら、新しいチャットで `level-01.png` を使って同じことをする（プロンプトの「レベル2」を「レベル1」に変えるだけ）。
6. できた絵をダウンロードして、上の表のファイル名で保存し、Claude に送る。

## 【さいしょのプロンプト】（コピーして そのまま 貼る）

```
添付した1枚目の画像は、私が手描きした子ども向けアプリのキャラクター「こぐまん」です。
2枚目は表情の参考資料です（表情の「形」だけを参考にしてください。絵のタッチは真似しないでください）。

1枚目の画像を元に、表情だけを変えた画像を1枚作ってください。

【変えるところ】
・目：参考資料の「にっこり」のような、上にふくらんだやさしい弧（⌒）の笑った目にする
・口：変えない（いまの口のまま）

【絶対に守ってほしいこと】
1. 顔の目と口以外は、1枚目の画像から何も変えない。体の形・耳・手足・鼻・色・線・位置・大きさ・向きをそのままにする
2. 構図・キャンバスの縦横の比率・キャラクターの位置と大きさを変えない。トリミング・拡大・縮小・回転をしない
3. 新しく描く目の線は、元の絵と同じこげ茶色（#573512）、同じ太さ（元の輪郭線と同じくらい）の、まるいペンで描いたようなシンプルな線にする
4. 目の位置と大きさは、元の目と同じ場所・同じくらいの幅にする（左右の目の間隔を変えない）
5. 絵のタッチは元の画像に合わせる。参考資料のふわふわした輪郭・水彩風の陰影・グラデーションは足さない
6. 背景は透明にする。透明にできない場合は、真っ白（#FFFFFF）の単色にする。影・地面・文字・きらきらなどの飾りは描かない
7. キャラクターを1体だけ描く。並べたり、説明の文字を入れたりしない

出力は画像1枚だけにしてください。
```

## 【2枚目以降のプロンプト】（1回に1つずつ送る）

**2枚目：わーい（笑った目＋あけた口）**
```
ありがとうございます。同じルールのまま、1枚目の元画像（手描きのこぐまん）からもう1枚作ってください。
・目：さきほどと同じ笑った目（⌒）
・口：参考資料の「わーい！」のような、少しあけた口にする。鼻の下からのびる短いたて線につながる形で、口のなかは赤み（#D6606A）、下にピンクの舌（#F6A0A6）。口のりんかく線はこげ茶色（#573512）で元の線と同じ太さ。口の幅は元の口と同じくらい
・ほかは何も変えない。背景は透明（できなければ真っ白）、影なし、1体だけ
```

**3枚目：まばたき（とじた目）**
```
同じルールのまま、1枚目の元画像からもう1枚作ってください。
・目：参考資料の「ねむい」のような、とじた目にする。目の位置に、元の目と同じくらいの幅で、少し下にまがったやさしい横線（‿ のような形）をこげ茶色（#573512）で描く
・口：変えない（元の口のまま）
・ほかは何も変えない。背景は透明（できなければ真っ白）、影なし、1体だけ
```

**4枚目：しゃべる（ふつうの目＋あけた口）**
```
同じルールのまま、1枚目の元画像からもう1枚作ってください。
・目：変えない（元の目のまま。白いハイライトもそのまま）
・口：2枚目と同じ、あけた口
・ほかは何も変えない。背景は透明（できなければ真っ白）、影なし、1体だけ
```

## 【やり直しのプロンプト】（ずれたとき）

体の形や色が変わってしまったとき：
```
顔の目と口以外が、元の画像から変わってしまっています（体の形・線・色・大きさ・位置）。
元の画像をそのまま使い、目と口のところだけを描きかえてください。ほかは1ピクセルも変えないでください。
```

タッチがちがうとき（ふわふわ・陰影がついた など）：
```
線のタッチが元の絵とちがいます。陰影・グラデーション・ふわふわした線は使わず、
元の絵と同じ、こげ茶色（#573512）の太さが一定のシンプルな線で描きなおしてください。
```

背景が白くならない・影がついたとき：
```
背景を透明（できなければ真っ白 #FFFFFF の単色）にして、影・地面・飾りを消してください。キャラクター以外は何も描かないでください。
```

## チェックリスト（できた絵を見るところ）

- [ ] キャラクターが1体だけ。文字や飾りがない
- [ ] 背景が とうめい か 真っ白
- [ ] 目の位置・幅が、元の絵とだいたい同じ（左右の目の間が広がったり狭まったりしていない）
- [ ] 線の色がこげ茶で、太さが元の線と同じくらい
- [ ] ほっぺ・陰影・ふわふわした線が足されていない
- [ ] 鼻の形が元の絵と同じ（鼻は使い回すので、変わっていたらやり直し）

体の線や耳の形が **少し** ちがうくらいなら、そのままでOKです（Claude が顔のところだけ使います）。

## できたら（Claude がやること）

1. 元の絵と重ねて、顔の位置をぴったり合わせる（大きさ・位置がずれていても、耳や体の輪郭を目じるしに合わせる）
2. 目・口のところだけを切り出して、パーツ（`eyes-smile`・`eyes-close`・`mouth-open`）にする
3. 元の絵から ふつうの目・口 と 顔を消した体 を作る
4. 重ねた見本を送って見てもらう → OKならアプリに入れる

## 注意

- ChatGPT はときどき、たのんでいないところ（体の形・色）を変えます。**1回で決まらないのはふつう** なので、やり直しのプロンプトを使ってください。
- ChatGPT の画像のサイズは元の絵（1620×2160）と同じにならないことがあります。Claude が合わせるので気にしなくて大丈夫です。
- できた絵の使い方（アプリでの公開など）は ChatGPT の利用規約にしたがいます。気になるときは代表が確認してください。
