# 無料プラン・トライアル・有料プランのしくみ（2026-11-24）

決めたこと・理由：`../plan/2026-11-24_free-plan-implementation.md`

## 1. どこで決めているか（1か所だけ）
`kids-app/plan.js` の `Plan.current()` が `"free"`／`"trial"`／`"paid"` を返します。上から順に見ます。
1. 有料のしるし（サーバーが「払っている」と答えた）が期限内 → **paid**
2. トライアルを始めて3日以内 → **trial**（2026-11-26 代表：7日 → 3日）（中身は有料と同じ）
3. それ以外 → **free**

| 変えたいもの | 直す場所 |
|---|---|
| 値段（780円・7,800円・先着580円・5,800円・50家庭） | `plan.js` の `PRICES` |
| 子どもの数・あいぼうの数・レベルの上限・ネットなし | `plan.js` の `LIMITS` |
| 各ジャンルの「ステージ1」のはんい | `plan.js` の `FREE_STAGE` |
| 無料で使えない親の機能（週のレポートなど） | `plan.js` の `PAID_FEATURES` |
| 支払いページ（Stripe の支払いリンク） | `paywall.js` の `PAY_LINKS_LIVE`（本番・空のあいだは「準備中」）／`PAY_LINKS_TEST`（開発用の住所とパソコンだけ。2026-11-26 入れた） |

### 無料プランを始めるスイッチ（2026-11-24）
`plan.js` の `FREE_PLAN_LIVE`。**false のあいだは「無料β」で、公開した住所では だれでも全部使える**（今までと同じ）。無料版を公開する日に true にする。パソコン（localhost）では false でも本当の判定になるので、無料・トライアル・有料を試せる。

## 2. それぞれのプランでできること
| | 無料 | トライアル（3日・1台1回） | 有料 |
|---|---|---|---|
| 19ジャンル | 最初のステージだけ（何回でも） | ぜんぶ | ぜんぶ |
| あいぼう | 1体・レベル5まで | 3体・レベル10 | 3体・レベル10 |
| 子ども | 1人 | 3人 | 3人 |
| 1日の時間の設定 | ○ | ○ | ○ |
| にがて れんしゅう・週のレポート・おけいこの中身を変える | 🔒 | ○ | ○ |
| ネットなしで全部 | ×（使ったものだけ残る） | ○ | ○ |

- 無料の進みは `state.freePos` に別に数えます。有料の進み（`hiraLevel` など）はさわらないので、有料になったら続きから
- トライアルや有料が終わっても、あいぼう・記録は消しません（レベル6以上に育っていても そのまま。次のレベルアップだけ止まる）

## 3. 有料にするとき（12月・サーバーを公開してから）
1. 親：保護者メニュー →「プラン・安心のしくみ」→ 月額／年額 → Stripe の画面で払う
2. 親：料金の画面の右上「購入済みの方・2台目の端末 ›」→ 確認の画面で メールアドレス →「確認コードを送る」
   - Stripe の支払いリンクの「支払い後のもどり先」を `https://<本番の住所>/?bought=1` にしておくと、払ったあと この確認の画面が自動で開く
   - Safari で開いているときは「ホーム画面に追加したアプリで使っている方は、そちらで確認」と出す（記録が別のため）
3. メールに届いた6けたのコードを入れる → この端末が有料に（1家族5台まで。2台目からも同じ入口）
   - 確認できたら **「ご購入ありがとうございます！」の画面**（2026-11-26 代表：感謝を伝えたい）：あいぼう3体（レベル3にそろえる）がはねる・紙ふぶき・使えるようになったもの（短く5つ。2026-11-27 代表：あいぼうも毎月1体ふやす予定なので「すべてのあいぼう」「毎月、新作の遊びとあいぼうを追加！」）・代表からのひとこと（さいごは「お気軽にチャットへご連絡ください！」。チャットは まだ ない）（`paywall.js` の `THANKS_LETTER`。【代表が直す】たたき台）。「お子さまに見せる」でホームへ → あいぼう3体が「やったー！ ぜんぶの あそびが ひらいたよ！…」（閉じた場合も、次にホームに来たとき1回。声は**まだ録音なし**）
4. 3日に1回、アプリがサーバーに「まだ払っているか」を聞きなおす。解約していたら無料に戻る
5. 端末を手放すときは「この端末の有料を外す」で5台の枠をあける

## 4. ためしかた（パソコン）
パソコンで動かしているとき（localhost）だけ、プランの画面の下に「開発用：プランを切り替える」が出ます。公開した住所では出ません。

### A. 無料：あ行が遊べる → か行がロック → ロック画面
1. ブラウザの記録を消してから開く（無料で始まる）
2. あいぼうを1体えらぶ → ほかの2体は うすくなって🔒（押すと「おうちの ひとと いっしょに あけてね」）
3. 「べんきょう」→「ひらがな」→ ステージ一覧が出る（ステージ1 あ ぎょう ▶／ステージ2〜 か ぎょう から 🔒）
4. 「▶ ステージ1 で あそぶ」→「あ」が出る。書くたびに あ→い→う→え→お→あ…（か は出ない）
5. もどって「ひらがな」→「🔒 ステージ2 を ひらく」→ 子ども向けのロック画面
6. 「おうちの ひとに みせる」→ かけざん → 正解すると料金の画面（もっと遊ぶには・月780円／年7,800円・3日間無料でためす）
7. 右上の「もどる」を押すと べんきょうの画面にもどる（子どもが止まらない）
8. 右上の「購入済みの方・2台目の端末 ›」→ 確認の画面（左に ①②③ の流れ、右に メールアドレスの欄）→「もどる」で料金の画面へ

### B. 無料のほかの上限
- 保護者メニュー →「＋ きょうだいを足す（有料）」→ 料金の画面（子どもは増えない）
- あいぼうがレベル5で おなかいっぱいになると「もっと おおきく なれるんだ」→ 1日1回ロック画面
- 「今週のようす」「中身を見る・変える」に🔒 → 料金の画面
- 料金の画面は 保護者メニューの**上**に出る（2026-11-25 直した：うしろに出ていて、保護者メニューを閉じると メールの欄が出てきた）

### C. トライアル
- 料金の画面の「3日間 無料でためす」→ ぜんぶ開く（タイルを押すとすぐ始まる・ステージ一覧は出ない）
- もう一度は押せない（1台1回）
- 開発用の切り替えを「ふつう」にして、4日目になると無料にもどる（テストは `tests/plan.test.js`）

### C-2. 3日間のようす（2026-11-26 代表：続けたい・続けさせたいと思える画面）
- **最終日（あと1日）**：ホームに来たとき、あいぼうが「3にち いっしょに がんばったね！ おうちの ひとに みせてね」（1回だけ）
- **おわったあと**：同じお知らせを、保護者が見るまで1日1回（3日まで）。「あとで」で閉じられる（子どもは止まらない）
- 「おうちの ひとに みせる」→ かけざん → **3日間のようす**（`app.js` の `trialSummary`）
  - 数字（遊んだ日・時間・問題数）／3日間でできるようになったこと（新しく書けた字・1日目と最後の日のくらべ・ためした遊び）／夢中になった遊び
  - 続けると この子は：ひらがな あと何字・あいぼう いまレベル何 → 10・にがての字・週のレポート・毎月の新作
  - 料金（1日あたり約26円・年額は2か月分おトク）と「無料プランでも」できること（せめない・正直に）
  - 左にあいぼうと「レベル1 → 3」（トライアルを始めたときのレベルを `trialSnap` にとっておく）、「有料プランで続ける」「無料プランで続ける」
- 料金の画面の「トライアルのようすを見る」からも、いつでも見られる
- 子どもの声「3にち いっしょに…」は**まだ録音なし**（録音リストに入れた。録音するまでは声なし）
- 計測：`trial_summary`（stage=1 はおわったあとに見た）

### D. 有料が今までと変わっていないこと
開発用の切り替えを「有料」にして：
- きょうだいを3人まで足せる（4人目は足せない）
- あいぼう3体をえらべる・レベル10まで育つ
- べんきょうのタイルに🔒がなく、押すとすぐ始まる。ひらがなは今までの順（し・つ・く…）で全部
- にがて れんしゅう・週のレポート・おけいこの中身を変える が使える
