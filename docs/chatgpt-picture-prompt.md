# ChatGPT で「せんかき」と「ものがたり」の 絵 を 作ってもらう プロンプト

2026-11-28 作成。代表：絵文字 は つかわず、せんかき と おはなし の 絵 を ChatGPT に かいて もらう。

- **いま の アプリ**：せんかき は フリー素材 の アイコン（Material Design Icons・単色）、ものがたり は 絵文字。絵 が とどいたら さしかえる
- **使う アカウント**：開発用（ChatGPT の 絵 は アプリ に 入れる ため。代表 の 個人 の アカウント で 作った 場合 も 使って よいが、どの アカウント で 作ったか を メモ）
- **絵 の 決まり**：「AI感」を さけたい（CLAUDE.md）。代表 の 手がき の キャラ に タッチ を あわせる。ふわふわ の 水彩・グラデーション・光沢・リアル な 影 は つけない

---

## A. せんかき の 絵（36まい → 6まい の シート で たのむ）

線 の 両はし に おく「はじまり の 絵」と「ゴール の 絵」です（例：ねずみ → チーズ）。
**1まい に 6こ ならべた シート** で たのむと、タッチ が そろい、回数 も へります。切りわけ は Claude が します。

### 【1まいめ の プロンプト】（コピー して 貼る。絵 を 1まい 添付）
```
添付した画像は、私が手描きした子ども向けアプリ（2〜6歳向け）のキャラクターです。
この絵と同じタッチで、子どもが「線をかく練習」で使う小さなイラストを作ってください。

【描くもの】
1枚の画像に、次の6つを 3列×2段 にならべてください（左上から右へ、次の段も左から）。
ねずみ、チーズ、いぬ、ほね、ねこ、さかな

【守ってほしいこと】
1. タッチは添付の絵に合わせる：こげ茶色（#573512）のまるいペンの、太さが一定のやさしい輪郭線＋ふんわりした単色のぬり
2. 水彩のにじみ・グラデーション・光沢・リアルな影・質感は入れない。シンプルでかわいく、2歳でも何かわかる形にする
3. 1つずつ正面か真横から、全体が見えるように描く。動物は顔がわかるように、にっこりした表情で
4. 6つの大きさをそろえる（1つが マスの 7割くらい）。となりと重ならないように、まわりに十分な余白をとる
5. 背景は真っ白（#FFFFFF）の単色。影・地面・文字・番号・枠線・きらきらなどの飾りは描かない
6. 画像は横長（3:2）にする
```

### 【2まいめ 以降 の プロンプト】（おなじ チャット で、1かい に 1まい）
```
ありがとうございます。同じタッチ・同じ大きさ・同じならべ方で、次の6つを作ってください。
（ここに シート の 6こ を 書く。例：はち、はな（ピンク）、うさぎ、にんじん、くるま（あか）、おうち）
```

### チェック（ダメ なら「〇〇 を 直して。ほか は 変えないで」）
- [ ] 6こ が はなれて いて、重なって いない
- [ ] 線 の 色・太さ が キャラ の 絵 と 同じ くらい
- [ ] グラデーション・光沢・文字 が ない
- [ ] 2さい でも 何 か わかる

## B. ものがたり の 絵（31まい）

ページ ごと の 絵 です。いちらん（ファイル名・文・かく もの）は **`docs/story-illustrations.md`**。
- 1 の「おさんぽ」は、えらんだ あいぼう が しゅじんこう に なる ので、**しゅじんこう は かかず 景色 だけ**（アプリ が あいぼう を 上 に かさねる）
- 2「すなば」は しょべるん、3「いもむし」は キャロ を かく
- **1話 ずつ**、おなじ チャット で 続けて たのむ（タッチ が そろう）。まず「おさんぽ」の 9まい で ためして、子ども の 反応 を 見る の が おすすめ

### 【さいしょ の プロンプト】（キャラ の 絵 を 添付。すなば なら しょべるん、いもむし なら キャロ。おさんぽ は こぐまん を タッチ の お手本 に）
```
添付した画像は、私が手描きした子ども向けアプリ（2〜6歳向け）のキャラクターです。
このアプリの「えほん」のページの絵を、1ページずつ作ってください。

【このおはなし】
（ここに おはなし の 名前 と、全部 の 文 を 貼る。例：「しょべるん の すなば」1 しょべるんは はたらく くるま。2 きょうは こうえんで おしごと です。…）

【守ってほしいこと（全ページ共通）】
1. タッチは添付の絵に合わせる：こげ茶色（#573512）のまるいペンの、太さが一定のやさしい輪郭線＋ふんわりした単色のぬり。やわらかいパステル調
2. 水彩のにじみ・強いグラデーション・光沢・リアルな影・写真のような質感は入れない
3. キャラクターを描くときは、添付の絵の形・色・顔をそのまま使う（新しい特徴を足さない）
4. 背景も描く（えほんの1ページのように）。ただし、ごちゃごちゃさせず、主役がひと目でわかる構図にする
5. 絵の中に文字・ふきだし・番号は入れない
6. 正方形（1:1）にする。大事なものは中央に寄せ、まわり1割には大事なものを置かない（角をまるく切るため）
7. 1回に1ページだけ作る

では、1ページめ「（ここに 1ページ め の 文）」を作ってください。描くもの：（docs/story-illustrations.md の「かく もの」）
```
