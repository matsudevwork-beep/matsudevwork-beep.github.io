保護者 が アプリ の 中 で「ぶにゅう の 運営」に 連絡 でき、代表 が スマホ の 管理ページ で お返事 する しくみ です。

## 保護者 の 見え方
- 保護者メニュー（はぐるま 2秒 → かけざん）→「チャットで連絡する」
- 書いて「送る」。たて に もって いる とき は 入力 シート（まわさない 画面）で 書く
- **はじめ の あいさつ**（2026-11-27 代表 の 文）：いつも いちばん うえ に「アプリのご質問や改善点、「こんな遊びがほしい」など、お気軽にお送りください！…」（`chat.js` の `CHAT_HELLO`。サーバー には 送らない）
- **自動 の お返事**（2026-11-27 代表）：送った すぐ あと に「お問い合わせありがとうございます。内容を確認し、2日以内には必ずお返事いたします。今しばらくお待ちください。」（`CHAT_AUTO`）。代表 が お返事 する まで は 1かい だけ（つづけて 送っても くりかえさない）。端末 の 中 だけ で 出す ので、管理ページ には 出ない（一覧 の 上 に その 説明 あり）。**「2日以内」は お客さん へ の 約束**
- お返事 が 来る と、はぐるま に **赤い 点**、ボタン に「お返事が届いています」。チャット を ひらくと 消える
- お返事 は 次 に アプリ を ひらいた とき・アプリ に もどった とき・チャット を ひらいて いる あいだ（20秒 ごと）に 届く
- 前 の やりとり は 端末 にも のこる（ネット が なくても 見られる。送る のは ネット が いる）
- **GitHub Pages（いま の 公開 の 住所）では 出ない**（サーバー が ない ため）。そこ では 今まで どおり 感想フォーム

## 代表 の 使い方（管理ページ）
- 開発用：https://bunyu-dev.matsu-dev-work.workers.dev/admin （本番 は 本番 の 住所 の /admin）
- ログイン：「コードを送る」→ 代表 の メール に 6けた → 入れる → 30日 そのまま
- 新しい 連絡 が 来ると 代表 の メール に お知らせ（おなじ 人 から は 30分 に 1かい）。メール の 中 に 管理ページ の 住所
- 一覧（#番号・プラン・未読）→ ひらいて お返事 を 書いて「送る」

## 守って いる こと
- 名前・メールアドレス は 持たない。端末 ごと の でたらめな 番号（計測 の 番号 とは べつ）の ハッシュ だけ
- 1年 たった やりとり は 毎日 の そうじ で 消す
- 保護者 の 文 は 画面 に 文字 として だけ 出す（HTML に しない）。送れる のは 1かい 1000字・1時間 20かい まで
- 管理ページ の ログイン は 1時間 5かい まで。コード は 10分・5かい まちがえ たら 使えない
- 本公開 の とき は プライバシーポリシー に「チャット の 内容 を 1年 保存」と 書く
