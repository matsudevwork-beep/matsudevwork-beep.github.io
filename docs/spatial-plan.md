# 空間把握（くうかん）の あそび の 検討（2026-11-09）

> 代表の依頼：「空間把握能力を高めるものを検討して取り入れてみて」
> ここは提案です。どれを本番に入れるかは代表が決めます。

## 結論
**まず「かたち うつし」（おてほん と おなじ に ぬる → 上級は かがみ）を試作で入れた。**
「べんきょう」→「ためしに やってみる」から遊べる。お子さんの反応を見て、次の1つを決める。

- 理由1：3〜6さい で できる。ルールが「おなじ に する」だけで、説明が いらない
- 理由2：「どこに・いくつ・どの むき」を くらべる練習になる（空間把握の 基本）
- 理由3：いまの マス目の しくみ（プログラミング・みちつなぎ）と 見た目が そろう。作る手間が小さい

## 事実と推測
- **事実（研究で言われていること）**：2〜4さい で パズル遊びを よくする子ほど、あとで「形を頭の中で動かす力」が高い、という報告がある（Levine ほか 2012）。積み木・形あわせ も 空間の力と関係が あると言われる
- **推測**：アプリの「かたち うつし」で 同じ効果が出るかは、まだ わからない。紙や積み木の遊びの かわり では なく、「入口」と考えるのが 安全
- **気をつけること**：「頭が よくなる」「空間認識能力が 上がる」と 言い切る 宣伝は しない（根拠が 弱い。ストアの審査でも 注意される）。「かたち を 見る・くらべる あそび」と 書く

## いれた もの：かたち うつし（`games-new.js` の `GAMES.shape`）
| レベル | 中身 |
|---|---|
| 1〜2 | 3×3 の マス。おてほん と おなじ ばしょ を ぬる（1いろ） |
| 3 | 4×4 |
| 4 | 4×4・2いろ（あか・あお を えらんで ぬる） |
| 5 | **かがみ**：まんなか の せん を はさんで、はんたい がわ に うつす |
| 6 | 5×5・2いろ |
| 7〜8 | かがみ・2いろ → 6×6 |

- ゆびで なぞると つづけて ぬれる。ぬった マス を もういちど さわると けせる
- ちがう ときは「どこか ちがう みたい。おてほん と よく くらべて みよう」（罰は なし）
- ごほうび：3もん で おやつ1こ

## つぎ の 候補（おすすめ順）
1. **かたち パズル**（ピース を ドラッグ して シルエット に はめる。上級は まわす）… 空間の あそびの 王道。手間：中
2. **つみき を かぞえる**（かくれて いる つみき も かぞえる）… 5〜6さい。手間：中（立体の 絵が 必要）
3. **どこ から 見た？**（あいぼう が 見て いる ものを えらぶ）… 5〜6さい。手間：大（絵が たくさん 必要）
4. **おなじ かたち を さがす**（まわして ある 形 から えらぶ）… 5〜6さい。手間：小

## 決めること（代表）
- 「かたち うつし」を 12がつ の しんさく 5こ に 入れるか（いまは 11がつ の 5こ に 入れていない）
- つぎ に 作る 候補（おすすめ：かたち パズル）
