# ChatGPT で しょべるん の 表情 を 作ってもらう プロンプト

2026-11-23 作成。こぐまん（`docs/chatgpt-face-prompt.md`）と同じやり方で、しょべるんの表情（にっこり・わーい・まばたき・しゃべる）の絵を ChatGPT に作ってもらうための手順とプロンプトです。

---

## 考え方（こぐまん と おなじ）

- 代表の絵をそのまま渡して、**顔だけ表情を変えた絵** を1枚ずつ作ってもらいます。
- できた絵から、Claude が **目と口のところだけ** を切り出して、アプリで重ねる部品にします（体の線が少しずれても、使うのは顔だけなので大丈夫）。
- 「ふつうの目」「ふつうの口」は今の絵から切り出せるので、頼むのは **ちがう表情のぶんだけ** です。

### しょべるん の 顔 の とくちょう（プロンプトに入れてある）
- 目：たてに少し長い **水色のまる**（ふちは青、中は明るい水色 #9DE4FC、白いハイライトあり）
- 口：こげ茶の線（#7D4C0D）の **やさしい にっこり の 弧（‿）**
- 顔の両がわに **オレンジのしま**（ほっぺではなく車のもよう）。これは変えない

## 手順

1. ChatGPT で **新しいチャット** をひらく（こぐまんの会話のえいきょうを受けないように）。
2. `level-02.PNG`（と、あれば表情の参考資料）を添付して、下の **【さいしょのプロンプト】** をそのまま貼って送る。
3. 1枚目（にっこり）ができたら、下の **チェックリスト** で見る。ダメなら **【やり直しのプロンプト】** を送る。
4. OKなら **【2枚目以降のプロンプト】** を順番に送る（1回に1枚）。
5. 4枚できたら、新しいチャットで `level-01.png` を使って同じことをする（プロンプトの「レベル2」を「レベル1」に変えるだけ）。
6. できた絵をダウンロードして、上の表のファイル名で `08_kids-app/illustrations/shoberun/parts-trial/` に保存し、Claude に「できた」と伝える。

## 【さいしょのプロンプト】（コピーして そのまま 貼る）

```
添付した1枚目の画像は、私が手描きした子ども向けアプリのキャラクター「しょべるん」（黄色いショベルカーの子）です。
2枚目は表情の参考資料です（表情の「形」だけを参考にしてください。絵のタッチは真似しないでください）。

1枚目の画像を元に、表情だけを変えた画像を1枚作ってください。

【変えるところ】
・目：水色のまるい目を、上にふくらんだやさしい弧（⌒）の笑った目にする。線はこげ茶色（#7D4C0D）
・口：変えない（いまのにっこりした口のまま）

【絶対に守ってほしいこと】
1. 顔の目と口以外は、1枚目の画像から何も変えない。体の形・ヘルメット・顔の両がわのオレンジのしま・色・線・位置・大きさ・向きをそのままにする
2. 構図・キャンバスの縦横の比率・キャラクターの位置と大きさを変えない。トリミング・拡大・縮小・回転をしない
3. 新しく描く目の線は、元の口と同じこげ茶色（#7D4C0D）、同じ太さの、まるいペンで描いたようなシンプルな線にする
4. 目の位置と大きさは、元の目と同じ場所・同じくらいの幅にする（左右の目の間隔を変えない）
5. 絵のタッチは元の画像に合わせる。ほっぺの赤み・陰影・グラデーション・ふわふわした線は足さない
6. 背景は透明にする。透明にできない場合は、真っ白（#FFFFFF）の単色にする。影・地面・文字・きらきらなどの飾りは描かない
7. キャラクターを1体だけ描く。並べたり、説明の文字を入れたりしない

出力は画像1枚だけにしてください。
```

## 【2枚目以降のプロンプト】（1回に1つずつ送る）

**2枚目：わーい（笑った目＋あけた口）**
```
ありがとうございます。同じルールのまま、1枚目の元画像（手描きのしょべるん）からもう1枚作ってください。
・目：さきほどと同じ笑った目（⌒）
・口：参考資料の「わーい！」のような、にっこり大きくあけた口にする。口のなかは赤み（#D6606A）、下にピンクの舌（#F6A0A6）。口のりんかく線はこげ茶色（#7D4C0D）で元の口の線と同じ太さ。口の幅は元の口と同じくらい
・ほかは何も変えない。背景は透明（できなければ真っ白）、影なし、1体だけ
```

**3枚目：まばたき（とじた目）**
```
同じルールのまま、1枚目の元画像からもう1枚作ってください。
・目：参考資料の「ねむい」のような、とじた目にする。水色の目を消して、同じ位置に、元の目と同じくらいの幅で、少し下にまがったやさしい横線（‿ のような形）をこげ茶色（#7D4C0D）で描く
・口：変えない（元の口のまま）
・ほかは何も変えない。背景は透明（できなければ真っ白）、影なし、1体だけ
```

**4枚目：しゃべる（ふつうの目＋あけた口）**
```
同じルールのまま、1枚目の元画像からもう1枚作ってください。
・目：変えない（元の水色の目のまま。白いハイライトもそのまま）
・口：2枚目と同じ、あけた口
・ほかは何も変えない。背景は透明（できなければ真っ白）、影なし、1体だけ
```

## 【やり直しのプロンプト】（ずれたとき）

体の形や色が変わってしまったとき：
```
顔の目と口以外が、元の画像から変わってしまっています（体の形・ヘルメット・オレンジのしま・線・色・大きさ・位置）。
元の画像をそのまま使い、目と口のところだけを描きかえてください。ほかは1ピクセルも変えないでください。
```

タッチがちがうとき（ふわふわ・陰影・ほっぺの赤み がついた など）：
```
線のタッチが元の絵とちがいます。陰影・グラデーション・ほっぺの赤み・ふわふわした線は使わず、
元の口と同じ、こげ茶色（#7D4C0D）の太さが一定のシンプルな線で描きなおしてください。
```

背景が白くならない・影がついたとき：
```
背景を透明（できなければ真っ白 #FFFFFF の単色）にして、影・地面・飾りを消してください。キャラクター以外は何も描かないでください。
```

## チェックリスト（できた絵を見るところ）

- [ ] キャラクターが1体だけ。文字や飾りがない
- [ ] 背景が とうめい か 真っ白
- [ ] 目の位置・幅が、元の絵とだいたい同じ（左右の目の間が広がったり狭まったりしていない）
- [ ] 線の色がこげ茶で、太さが元の口の線と同じくらい
- [ ] 顔の両がわのオレンジのしまが、元のまま残っている
- [ ] ほっぺの赤み・陰影・ふわふわした線が足されていない

ヘルメットや車輪の形が **少し** ちがうくらいなら、そのままでOKです（Claude が顔のところだけ使います）。

## できたら（Claude がやること）

1. 元の絵と重ねて、顔の位置をぴったり合わせる
2. 目・口のところだけを切り出して、パーツにする（`../illustrations/shoberun/parts-trial/`）
3. `tools/build_face_parts.py` を しょべるん（`car`）にも使えるように直して、`kids-app/img/face/car-NN-<表情>.webp` と `face-parts.js` を作る
4. 重ねた見本を送って見てもらう → OKならアプリに入れる

## 注意

- ChatGPT はときどき、たのんでいないところ（体の形・色）を変えます。**1回で決まらないのはふつう** なので、やり直しのプロンプトを使ってください。
- ChatGPT の画像のサイズは元の絵（1206×2622）と同じにならないことがあります。Claude が合わせるので気にしなくて大丈夫です。
- できた絵の使い方（アプリでの公開など）は ChatGPT の利用規約にしたがいます。気になるときは代表が確認してください。
