# ものがたり の 絵（買う 絵 の いちらん）

2026-11-22 代表：ものがたり の 絵 を、えもじ から イラスト に したい。どの 絵 を 買えば 反映 できるか。

## けつろん
- **ぜんぶ で 31まい**（3つ の おはなし。おなじ 絵 で よい ページ は 1まい に まとめた）
- 絵 を `kids-app/img/story/` に **ファイル名 どおり** に おけば、アプリ が じどう で えもじ の かわり に 出す（コード を なおす 必要 なし）
- まだ ない ページ は いま の えもじ の まま なので、**1まい ずつ ふやして よい**

## 絵 の きまり（イラストレーター に わたす もの）
| こと | めやす |
|---|---|
| 大きさ | **正方形 1200×1200px** 以上（アプリ では 正方形 に ちかい わく に 入る） |
| 背景 | 背景 あり（えほん の 1ページ の ように）。まわり は かどまる で きりとる |
| 形式 | PNG で もらう → アプリ 用 に WebP（長い 辺 800px）に して おく（Claude に「ものがたり の 絵 を 入れて」で できる） |
| 文字 | 絵 の なか に 文字 は 入れない（文 は アプリ が 出す） |
| タッチ | キャラ は 代表 の 手がき の 絵 に あわせる（こぐまん・しょべるん・キャロ の 資料 を わたす） |

## 気をつける こと：「おさんぽ」の しゅじんこう は えらんだ あいぼう で かわる
- 「{name}の おさんぽ」は、こぐまん・しょべるん・キャロ の **どれ を えらんで いても 同じ おはなし**。しゅじんこう を 絵 に かくと、3まい ずつ（×3）に なる
- **おすすめ**：おさんぽ の 絵 は **しゅじんこう を かかない 景色 だけ** に して、アプリ が いま の あいぼう の 絵 を うえ に かさねる（あいぼう の 絵 は もう ある）。→ 絵 は 9まい の まま。かさねる しくみ は 絵 が とどいたら 作る
- 「すなば」は しょべるん、「いもむし」は キャロ が しゅじんこう で きまって いる ので、キャラ を かいて よい
