# AI機能を「売り」にするなら（調査と検討）2026-11-07

> 代表の質問：「仮にAI機能搭載を特徴として売るとしたら、どんな機能が最適？」
> ここに書いてあるのは提案です。どうするかは代表が決めます。

## 結論
**「AIせんせいが、書いた字を見てくれる」＋「にがてを見つけて、きょうのおけいこを組む」＋「おうちの人への週のレポート」を、全部スマホの中で動かす**のがおすすめです。
売り文句は「AIは端末の中だけ。お子さまの字や声は外に送りません」。
生成AIとの自由な会話や、声で読みを判定する機能は、いまは入れないほうがよいです。

## なぜこの組み合わせか（推測を含む）
- 大手は「AIと話す」で勝負している。同じ土俵では勝てない。小さく作るなら「書く」を深くするほうが勝ち目がある。
- 「外に送らないAI」は、保護者の不安（55%が悩んでいる）にそのまま答えられる。広告・外部解析を入れない、いまの方針とも合う。
- 子どもの声の認識はまだ誤りが多い。「ちがうよ」と言うと、子どものやる気をこわす。
- 月480円だと、会話のたびにお金がかかる機能は、使う子ほど赤字になりやすい。

## 気をつけること
- **ただの決まりごと（ルール）で動くしくみを「AI」と言わない。** 言いすぎると、実際より良く見せる表示として問題になるおそれがある。A は本当に機械学習（ML Kit）を使うので「AI」と言える。B と C は「その子に合わせて」と言う。
- A でも、判定がきびしすぎると子どもがいやになる。いまと同じく「ほめる・できるようになった」を中心にする。
- iOS で ML Kit を使うには、アプリ化（Capacitor）のあとに組みこむ必要がある。それまではブラウザの中で、お手本との形のくらべ（いまの延長）で試作できる。

## 次にやること（案）
1. A の試作：書いた字とお手本の形をくらべて、「とめが じょうず」「もうすこし まっすぐ」など1つだけ言う（ブラウザで試せる範囲）。
2. B：にがての字（まっすぐさが低い・時間がかかる）を、きょうのおけいこに1こ混ぜる。
3. C：保護者メニューに「今週のようす」（できるようになったことの まとめ）を出す。
