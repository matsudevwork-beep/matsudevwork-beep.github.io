# イラスト依頼リスト（あいぼう）

いまは絵文字や仮の絵を使っているところを、キャラクターと同じタッチ（ゆるキャラ進化図鑑）でそろえるためのリストです。
イラストレーターさんへの依頼（方式B）といっしょに出す想定です。

## 絵のタッチ（共通）
- キャラクター（こぐまん・しょべるん・キャロ）と同じ：やわらかいパステル色、こげ茶の細いふち線、白いつや、まるっこい形
- 背景は透過（PNG）。正方形、1000px以上
- 幼児が一目でわかる形。こまかい模様は入れない

## A. ボタン・あそびのマーク（5点）
今は試作で、Claude が同じ方向性のマークを仮に描いています（`kids-app/characters.js` の `UI_ICONS`）。

| マーク | 使う場所 | いまの仮の絵 |
|---|---|---|
| ボール | あそぶ「ボール」・投げるボール | クリーム色のサッカーボール |
| あわ | あそぶ「おふろ」・おふろの泡 | 水色のあわ3つ |
| 音符 | あそぶ「ダンス」・おどるときの音符 | オレンジの8分音符 |
| ふきだし | あそぶ「おはなし」 | クリーム色のふきだし |
| 消しゴム | なぞり「けして やりなおす」 | ピンクと水色の消しゴム |

ほかに、みず・ごはん（`makeWaterSVG` / `makeFoodSVG`）も同じタッチで描きなおすとよい。
