## 1つずつの検討

### ① 2歳の お絵かき（ペンに なれる・手首を つかう）
| 項目 | 内容 |
|---|---|
| ねらい | 手首を回す・左右にふる・とんとん打つ動きに慣れる。上手・下手は判定しない |
| 流れ | (1) 絵が出る（こぐまんの頭・木・くも など）→ (2) あいぼうが見本を かいて見せる（ゆっくり動くアニメ）→ (3) 子どもが自由にかく → (4) 「できた」で絵が ぴょんと動いてほめる |
| お題の例（手首の動き別） | ぐるぐる：こぐまんの かみのけ・ひつじの もこもこ・木の はっぱ ／ ギザギザ：ライオンの たてがみ・やまの くさ ／ ちょんちょん：くもから あめ・いちごの つぶ・てんとうむしの もよう ／ よこ線：しょべるんが ほる みち ／ たて線：くさ・ひげ |
| 判定 | しない。かいた量・はみ出しは見ない。かけば必ず ほめる |
| まえより できたこと | 「ぐるぐる が おおきく なったね」「いっぱい かけたね」（線の長さ・ぐるぐるの大きさで比べる） |
| 2歳ならではの工夫 | 線は太く、色は1タップで変えられる（3〜4色）。手のひらが画面にふれても動かないように、最初の1本の指だけを使う。ボタンは大きく、少なく。読み上げは短く |
| かいた絵 | 端末の中だけに保存して「さくひん」で見られる（外には送らない） |
| 作る手間 | 小〜中（線をかく しくみは できている。お題の絵と見本の動きを作る） |
| 気をつけること | 2歳の画面の時間は短めがよい。保護者メニューの「あそぶ時間の めやす」を、2歳むけは10分に すすめる |

### ② たしざん・ひきざん（かずの かぞえかた）
- いきなり「1＋2＝」の式にしない。**ものを使ったお話**から入る。
  1. あわせて いくつ：「ひよこ が 2わ。1わ きたよ。ぜんぶで なんわ？」
  2. のこり いくつ：「りんご 3こ。しょべるん が 1こ たべた。のこりは？」
  3. 5 と 10 の まとまり：「5 は 2 と いくつ？」（てんびんの左右を つりあわせる形で作れる）
  4. 4〜5歳の上級だけ、式（2＋1）を そえる
- かぞえかたの練習：1つずつ さわって数える・「とばして かぞえない」を確かめる（いまの「かぞえる」の延長）
- 作る手間：小（かず・てんびん の部品を使い回せる）

### ③ プログラミング（めあてに むけて 指示を くみあわせる）
- 例：あいぼうを おやつの ところへ つれていく。**やじるしカード（まえ・みぎ・ひだり）を ならべてから「スタート」**。その通りに あいぼうが動く。まちがえたら、とちゅうで止まって「どこを なおす？」
- だんかい
  1. カード1まい（すぐ となり）
  2. カード2〜3まい
  3. 4〜6まい、まがりかど あり
  4. 上級：「くりかえし」カード（まえ×3）
- 「考える」の柱に入る。保護者に説明しやすい（小学校でプログラミングが必修）。
- 作る手間：中（いまの めいろ・みちつなぎ の歩くアニメを使い回せる）
- 気をつけること：対象は4〜5歳。2歳には むずかしいので、べんきょうの一覧で年齢のめやすを出す

### ④ アルファベット・英単語
- アルファベットを書く：大文字26字から（小文字は形が似ていて むずかしいので あと）。書き順データは、すうじ と同じく手作りする（KanjiVG には入っていない）。
  - 手間は小〜中。ただし、書き順は国や教材でちがうことがある。日本の小学校の教え方に合わせる
- 英単語：絵 → 英語の声 → 「A は apple」。さわると読み上げ
  - 声：スマホの読み上げ（英語）なら すぐ使えるが、機械っぽい。売りにするなら、英語の録音が必要（費用がかかるかもしれない → 代表に確認が必要）
- 売りやすさは高い（保護者の関心が強い）。ただ、柱の外なので「英語もできる」と広げすぎると、何のアプリかが ぼやける
- 字を読むAIは、同じ作り方でアルファベットにも使える（大文字26字なら ひらがなより かんたん）
