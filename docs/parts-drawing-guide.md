# あいぼう を パーツ分け で 描く 手順（B案・方式B）

2026-11-20 作成。手を上げる・手をふる・わらう・まばたき などの動きをつけるために、絵を「パーツ（部品）」に分けて書き出す手順です。
動画編集でいうと、**1枚の写真ではなく、人物・背景・テロップを別々のトラックに置く**イメージです。トラックが分かれていれば、手だけ動かす・目だけ変える ができます。

---

## まずは こぐまん だけ・1レベルだけで試す

いきなり全部は描かず、**こぐまん レベル9（てぶくろ）** など、手がはっきりしている1枚で試します。
うまく動いたら、ほかのレベル・ほかのキャラに広げます。

---

## 1. キャンバス（紙）のきまり

- **いままでと同じキャンバス**（同じ大きさ・同じ位置）で描く。
  - 今回の10枚は、どれも同じ場所に体が描かれていました。これがとても大事です。位置がそろっていると、パーツを重ねたときにぴったり合い、**笑った目・口は全レベルで使い回せます**。
- 背景は **とうめい**（白で塗らない）。
- かげ・消し忘れのペンは、あっても大丈夫（こちらで外します）。でも、**パーツのレイヤーの中には描かない**でください。

## 2. レイヤー（重ねる紙）の分け方

| レイヤー名（書き出すファイル名） | 中身 | 何に使うか |
|---|---|---|
| `body` | 体・耳・しっぽ・かざり（手と顔のパーツ以外ぜんぶ） | 土台 |
| `arm-left` | 左手だけ（りんかく線も） | 手を上げる・ふる |
| `arm-right` | 右手だけ | 手を上げる・ふる |
| `eyes` | ふつうの目 | まばたきのもと |
| `eyes-smile` | 笑った目（「^ ^」の形） | わらう |
| `eyes-close` | とじた目（「ー ー」） | まばたき・ねむい |
| `mouth` | ふつうの口 | |
| `mouth-open` | あけた口 | しゃべる・わらう |

**大事なポイント**
1. **手の下の体も描いておく。** 手を上げると、手があった場所が見えます。`body` には、手が付いていない形の体を、りんかく線までつなげて描いてください（手をどけても穴があかないように）。
2. **手のつけ根を少し長めに描く。** 回したときに体とのつなぎ目にすき間が出ないように、つけ根を体の内側に少し入るくらいまで描きます。
3. **顔のパーツは、体と同じキャンバスの同じ位置に。** 目だけ別のキャンバスに描くと、位置がずれます。
4. **ほっぺの色**は `body` に入れたままでOK（動かさないので）。

## 3. 書き出し

- 形式：**PNG（背景とうめい）**。レイヤーを1枚ずつ、キャンバス全体の大きさのまま書き出す（切り取らない）。
- ファイル名：`koguman-09-body.png`、`koguman-09-arm-left.png` のように、**キャラ名-レベル-パーツ名**。顔パーツは全レベル共通なら `koguman-eyes-smile.png` のようにレベルなし。
- いままでどおり **いつもの1枚絵（全部重ねたもの）** も送ってください（見比べ用）。

## 4. 送ったあと（Claude がやること）

1. パーツを重ねて、もとの1枚絵と同じに見えるかを確かめる
2. 背景・よぶんな線を外して、軽い形（WebP）にする
3. アプリで動きをつける：
   - タップ → 手をふる／両手を上げてばんざい
   - ほめられたとき → 目が「^ ^」になって わらう
   - しゃべっているあいだ → 口がぱくぱく
   - ときどき → まばたき
4. 動画やスクショで見てもらう

## 5. 描く量のめやす

| | 描くもの | 枚数 |
|---|---|---|
| 顔（キャラごとに1セット） | 目・笑った目・とじた目・口・あけた口 | 5枚 × 3キャラ |
| 手（レベルごと） | 体・左手・右手 | 3枚 × 10レベル × 3キャラ |

手は、てぶくろ・マントなど見た目が変わるレベルだけ描きなおし、**同じ形のレベルは使い回せます**（例：こぐまんのレベル2〜8は手の形が同じなら1セットでよい）。

---

わからないところは、描きかけのファイルを送ってもらえれば、分け方を一緒に見ます。
